The original recovery pack preserves 14 original texts, recovery notes and structured indexes. Initial app import: 35 searchable sources, 109 selectively normalized assertions, 44 timeline entries. See SOURCE_INSPECTION.md for original file counts.

The separate evidence review processed 46 Discord HTML channel exports / 1,140 messages; the Drive ZIP's 31 files; three tracker versions; six earlier source texts; instructions and the 27 user answers. The latest campaign tracker is user-designated. Original review totals: 88 source records and 3,930 evidence passages. All supplied bytes remain preserved in the original archives and review package.

The new application import adds all 88 metadata/extraction records, including 82 nonempty texts, and 40 reviewed facts. Application total is 123 source rows. Repeated versions are kept separate by provenance; this is not a count of unique original documents. Extracted text is indexed by source lines; native Discord message-level relational linking is not yet implemented in the app.

The complete original Discord and Drive archives and latest workbook are under evidence/canon-review-2026-10-20/originals. Each is checked against SHA256SUMS.json during import. The reviewed JSON seed is also checksummed and rebuilds an app database without a checked-in live SQLite file.

Processing all supplied sources does not mean Reunion's history is complete. Additional attachments, transcripts, maps and primary corroboration can still be supplied. Some sources are empty or limited media; these limitations are preserved in the separate review report.
